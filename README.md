# Capy Club

Landing page for Pilates, Please and Capy Takes a Napy coloring books, with interactive coloring previews and Pilates merchandise.

## Preview locally

Run `python3 -m http.server 8000` from this folder, then open `http://localhost:8000`.

The site uses plain HTML, CSS, and JavaScript. All artwork, fonts, coloring region maps, and the studio sales sheet are included.

Book and merchandise prices are placeholders. The shopping bag and checkout are a demo.
